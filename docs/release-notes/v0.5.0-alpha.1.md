# Fable 0.5.0-alpha.1 — source preparation

Primary workflow: `$fable-verify`. Map each acceptance criterion to exact source,
observations, remaining work and a smallest next action before merge or handoff.
Quick and deep coverage use the same versioned artifact. The existing six public
skills remain supported. Review and repair are separate requests.

This version adds working-tree/index stale-evidence detection, actual local
source/Node-check observations, explicit hosted-check publisher/name/SHA matching,
separate install-byte observations, untrusted-artifact rendering, and permission-free
handoffs. Optional Memory export is data only and is not a qualified importer.

Model preferences are centralized with balanced/deep/economical profiles. The
selected client performs read-only catalog preflight, preserves explicit overrides
and reports supported fallback choices. GPT-6.1 Sol is preferred when the chosen
Codex surface advertises it. Catalog presence is not account-access proof.

The original closeout ledger remains record accounting; `RECORDS_SATISFIED`
never means semantic completion. Saved JSON does not authenticate observations.
Hashes prove identity, not correctness, and the Node adapter is not an OS sandbox.

Run `node examples/completion-verification/demo.mjs`, `npm test`,
`npm run validate` and `npm run validate:artifact` from the full source checkout.
Back up a verified installed copy before a separately requested source update;
start a fresh Codex session after installing. See the upgrade guide for rollback.

This is an unreleased source version. Do not infer merge, signed release, npm
publication, directory approval, activated user sessions or deployed production.
Historical lexical benchmark records remain unchanged; broad effectiveness is
not established by synthetic regression fixtures or a small matched comparison.
